# PrimOO Workspace

## Layout
- Repo root: all Primoo work. Code, dbt projects, SQL, notebooks, scripts.
- `PrimOO Obsidian Vault/`: Obsidian vault. Markdown notes only.
- `PrimOO Obsidian Vault/.obsidian/`: Obsidian config. Never edit or read.

## Hard rules
- Never write `.py`, `.sql`, `.yml`, `.csv` or data files into the vault.
- Never write working notes or scratch `.md` files into the repo root.
  Notes belong in the vault.
- Never edit files inside `.obsidian/`.

## Session start
Read `PrimOO Obsidian Vault/_Index.md` for prior context before
starting substantive work.

## Capturing notes
When I ask you to save, log, capture, or write up anything, use the
`vault-note` skill. All Obsidian conventions are defined there.
